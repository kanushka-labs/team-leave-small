# Approvals

## Purpose

Managers see their team's pending leave requests and approve or reject each
one with a comment.

Needs: F1.

## User Stories

- F2.1 As a manager, I see my team's pending leave requests in one list, oldest first.
- F2.2 As a manager, I approve a pending request.
- F2.3 As a manager, I reject a pending request with a comment explaining why.
- F2.4 As a manager, I view my team's leave request history, including past approvals and rejections.

## Decisions

- A comment is required when rejecting a request; optional when approving.
- A decision, once made, is final — a manager cannot reverse an approval or a rejection.
- A manager sees and decides only their own team's requests (see [Product-wide](../product-wide.md)).
